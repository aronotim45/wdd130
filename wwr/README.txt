RIVER RUSH RAFTING — W03 ABOUT PAGE

1. Open your wdd130 folder in VS Code.
2. Copy the wwr folder into wdd130.
3. Add the required image files to wwr/images using these exact filenames:
   - rafting-logo.png
   - rafting-hero.jpg
   - happy-rafter.jpg
   - rafting-history.jpg
   - facebook-icon.png
   - instagram-icon.png
   - youtube-icon.png
4. Keep each image at or below 125 KB and use suitable, clear images.
5. Open wwr/about.html with Live Server.

The HTML and CSS are complete starter files. Replace the fictional company name,
text, and author name if your instructor requires different details. The other
navigation pages (index.html, trips.html, contact.html) will be created in later
assignments, so those links will not work until those files exist.
